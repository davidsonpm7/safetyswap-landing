SafetySwap - landing page de waitlist
======================================

Este é um projeto Next.js standalone (não depende de nenhum outro app).

Como rodar:

1. npm install
2. npm run dev
3. Abrir http://localhost:3000

Requer Node.js 22.5+ (o módulo node:sqlite é nativo do Node, sem precisar
instalar nada extra).

Observação: o banco data/leads.db é criado sozinho (pasta incluída) na
primeira vez que o servidor sobe. Não precisa criar nada manualmente, e
ele nunca é commitado (está no .gitignore).
